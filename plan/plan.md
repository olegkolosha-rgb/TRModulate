# Modulate Transcriber — веб-приложение для транскрибации

## Что это
Веб-инструмент, который принимает аудио/видео, отправляет его в Modulate Velma-2 STT,
показывает результат и даёт скачать транскрипт в TXT, SRT и JSON.

## Для кого
Для тех, кто сейчас запускает Python-скрипт вручную: нужен удобный интерфейс в браузере
вместо консоли, с историей прошлых транскрибаций.

## Основные возможности и опыт
- Загрузка файла в браузере (аудио и видео): перетаскивание или выбор, с индикатором прогресса загрузки.
- Автоматическая подготовка: из видео извлекается аудио, крупные файлы сжимаются перед отправкой; при ошибке «слишком большой файл» выполняется повторная попытка с меньшим битрейтом.
- Переключатели параметров Modulate перед отправкой: разделение по спикерам (диаризация), сигнал эмоций, акцент, детекция дипфейка, PII/PHI-теги.
- Просмотр результата: полный текст, список сегментов с таймкодами, спикерами и эмоциями.
- Скачивание результата в TXT, SRT (с разбивкой по предложениям и корректными таймкодами) и JSON.
- История транскрибаций: список прошлых результатов с датой и именем файла, повторный просмотр и скачивание.
- Понятная обработка ошибок: отсутствие ключа, слишком большой файл, сбой API — показываются человеку словами.
- Визуально аккуратный интерфейс с продуманным сочетанием цветов.

## Phase 1: что будет сделано сейчас
- Экран загрузки с перетаскиванием файла, переключателями параметров и прогрессом.
- Отправка в Modulate Velma-2 STT, извлечение аудио из видео и сжатие при необходимости, повтор при «413».
- Экран результата: текст, сегменты с таймкодами/спикерами/эмоциями, кнопки скачивания TXT/SRT/JSON.
- Сохранение каждой транскрибации в историю и отдельный экран истории с повторным доступом.
- Ключ Modulate API вводится в начале сборки и хранится в настройках окружения.
